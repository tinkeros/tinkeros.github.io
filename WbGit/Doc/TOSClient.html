TOSClient


There is a python server for TinkerOS tos_server.py which runs on Linux machines 
(in either server or client mode) which can connect to TinkerOS over real or 
virtual serial ports to exchange files, clipboard contents, fetch URLs or 
execute commands on the remote server.

See ::/Python/README.md for how to set up and run tos_server.py.  Once it is 
running and reachable over a COM port, the following functions may be available 
to you:

Connecting
InitTOSClient() Probes the COM ports for a running tos_server.py and remembers 
which port it's on.  You normally don't need to call this yourself -- every 
function below calls it for you (via TOSServerCheck()) the first time it's 
needed.

Files
Fget(filename, local_name=NULL) Downloads filename from the host's transfer 
directory to local_name (or the file's base name if omitted).  Returns the 
number of bytes transferred, or 0 on failure.

Fput(filename, remote_name=NULL)        Uploads filename to the host's transfer 
directory as remote_name (or the same name if omitted).  Returns the number of 
bytes transferred, or 0 on failure.

Dput(src_files_find_mask, remote_dir=NULL, no_mask=TRUE, sync=FALSE, 
bin_files=TRUE) Uploads a whole directory tree matching src_files_find_mask to r
emote_dir on the host.  Returns the count of files copied.

Dsync(src_files_find_mask, remote_dir=NULL, no_mask=TRUE, bin_files=FALSE)      
Like Dput() but skips files whose remote MD5 hash already matches (via FCmpHash(
)), so only changed files are actually transferred.  Skips binary/data files by 
default.

Dget(dir=".", strip=0)  Downloads every file under dir on the host into the 
current directory, recreating subdirectories as needed and skipping files whose 
local copy already matches by hash.

Hdir(dir=".")   Prints a listing of dir (relative to the host's transfer 
directory), non-recursive.

Clipboard
ClipGetStr()    Returns the host clipboard text as a string, or NULL on failure.

ClipGet()       Prints the host clipboard text.

ClipPutStr(send_text)   Sets the host clipboard to send_text.

ClipPut()       Copies the current TinkerOS clipboard to the host clipboard.

ClientClipHijack()      Hijacks the cut/copy/paste key handlers so TinkerOS's 
clipboard is automatically mirrored to/from the host clipboard, as long as a 
server is found.

URLs
URLGet(url, filename)   Has the host fetch url (unmodified/raw bytes) and saves 
the result to filename.

URLGetTextStr(url)      Has the host fetch url and HTML-strip it, returning the 
extracted text as a string.

URLGetText(url) Like URLGetTextStr() but prints the result instead of returning 
it.

Host Info
HGetOSStr()     Returns the host OS name (e.g. "Linux") as a string, or NULL on 
failure.

HGetOS()        Like HGetOSStr() but prints the result instead of returning it.

Remote Execution
HExecToStr(cmd) Runs cmd as a non-interactive shell command on the host and 
returns its output as a string.

HExec(cmd)      Like HExecToStr() but prints the output instead of returning it.

Misc
DirMks(dirs)    Local helper: creates an entire local directory tree (like mkdir 
-p), used internally by Dget() when recreating remote directory structure.
