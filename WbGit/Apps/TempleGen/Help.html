TempleGen

                 Sega Genesis / Megadrive Emulator for TinkerOS

Controller
  Arrow Keys - D-Pad          Enter - Start
  Z / X / C  - A / B / C buttons

Emulator Keys
  P - Pick ROM file         S - Save state
  R - Reset the console     L - Load state
  G - Game Genie codes
  Space - Pause / resume
  1 / 2 - Window scale: 1x is a bordered 320x240
          window; 2x fills the screen (640x448, borderless,
          TV overscan cropped).
  ESC / Q - Quit

Saves
  S writes the machine state next to the ROM
  ("Sonic.BIN" -> "Sonic.SAV.Z"); L restores it.
  Cartridge SRAM is not emulated -- use save states instead.

Sound
  Load /Demo/Snd/HDAudio.HC and /Demo/Snd/HDMixer.HC before
  TempleGen; the YM2612+PSG appear as the "GEN" mixer
  source.  The Z80 sound CPU is emulated, so both kinds of
  Sega sound driver play: the ones the 68000 runs itself
  (Sonic 1) and the ones uploaded to the Z80 (Sonic 2, 3
  and most later games), sampled drums included.

ROMs
  ROMs are not included.  Put .BIN, .GEN or .MD files
  (optionally .Z-compressed) in this app's "Roms"
  subdirectory.  The picker lists them at startup and
  P reopens it any time: Arrows move, Space/Enter pick,
  ESC backs out.
