TempleNES

                           NES Emulator for TinkerOS

Play NES (.nes) ROMs in a TinkerOS window.  Emulates the
6502 CPU, the 2C02 PPU, the 2A03 APU and mappers 0 (NROM),
1 (MMC1), 2 (UNROM), 3 (CNROM), 4 (MMC3) and 7 (AxROM).

Controller
  Arrow Keys - D-Pad          Enter - Start
  Alt or X   - A button       Tab   - Select
  Ctrl or Z  - B button

Emulator Keys
  P - Pick ROM file         S - Save state
  R - Reset the console     L - Load state
  Space - Pause / resume
  1 / 2 - Window scale: 1x (256x240) or 2x (512x448,
          TV overscan crop).  Dragging the window border
          also switches the scale.
  ESC / Q - Quit

Saves
  S writes the machine state next to the ROM
  ("Game.nes" -> "Game.BIN.Z"); L restores it.  Carts
  with battery SRAM (Zelda and friends) also save
  "Game.SRM" automatically on quit or ROM switch.

Sound
  Load /Demo/Snd/HDAudio.HC and /Demo/Snd/HDMixer.HC before
  TempleNES; the APU appears as the "NES" mixer source.
  Without them the emulator runs silent.

ROMs
  ROMs are not included.  Put .NES (or compressed .NES.Z)
  files in this app's "Roms" subdirectory.  The picker
  lists them at startup and P reopens it any time:
  Arrows move, Space/Enter pick, ESC backs out.
